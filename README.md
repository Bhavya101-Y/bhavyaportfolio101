## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/bhavya-portfolio.git
```

Navigate to project folder:

```bash
cd bhavya-portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
